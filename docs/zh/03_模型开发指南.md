# 模型开发指南

## 项目脚手架（推荐）

使用 `light-server init` 快速生成项目：

```bash
light-server init my_project --template llm --model-name my_llm
```

### 模板说明

| 模板 | 适用场景 | 包含内容 |
|------|----------|----------|
| `empty` | 通用场景，从零开始 | 空的 LitAPI 骨架 |
| `llm` | 大语言模型服务 | decode_request 解析 OpenAI 风格请求 |
| `cv-classify` | 图像分类 | 接收 base64 图片，输出分类结果 |
| `cv-detect` | 目标检测 | 接收 base64 图片，输出检测框 |
| `nlp` | NLP 文本处理 | 文本分类 / 情感分析骨架 |

脚手架还会生成 `Dockerfile`、`docker-compose.yml`、`Makefile` 和 GitHub Actions CI 配置，直接可用。

## 模型仓库规范

遵循 Triton 风格布局：

```
model_repo/
  {model_name}/
    {version}/
      model.py       # 必须包含 LitAPI 子类
      config.yaml    # 可选：max_batch_size, batch_timeout 等
```

- `model_name`：模型目录名，在管理 API 和推理端点中作为标识
- `version`：版本号字符串（如 `1`、`2`），支持多版本并存
- `model.py`：必须包含一个继承自 `LitAPI` 的类

## LitAPI 生命周期

```python
from light_server import LitAPI

class MyAPI(LitAPI):
    def setup(self, device):
        """初始化模型、加载权重。device 由 light-server 分配。"""
        self.model = load_model()

    def decode_request(self, request, **kwargs):
        """将 HTTP JSON 请求解析为 predict 可处理的输入。"""
        return request["input"]

    def predict(self, x, **kwargs):
        """执行推理。当 batching 启用时，x 为列表。"""
        return self.model(x)

    def encode_response(self, output, **kwargs):
        """将 predict 的输出编码为 JSON 响应。"""
        return {"result": output}
```

### 方法说明

| 方法 | 触发时机 | 说明 |
|------|----------|------|
| `setup(device)` | Worker 进程启动时 | 每个 worker 独立调用一次，`device` 为分配的加速器 |
| `decode_request(request, **kwargs)` | 每个请求 | 解析 HTTP 请求体为模型输入 |
| `predict(x, **kwargs)` | 每个请求/批次 | 执行实际推理 |
| `encode_response(output, **kwargs)` | 每个请求 | 编码为 JSON 返回给客户端 |

### setup 中的配置读取

```python
def setup(self, device):
    # 从 config.yaml 读取自定义字段
    self.max_length = self.config.get("max_length", 512)
    self.threshold = self.config.get("threshold", 0.5)
    self.logger.info(f"max_length={self.max_length}")
```

`self.config` 是 `config.yaml` 解析后的字典，`self.logger` 是结构化日志记录器。

## 批处理（Batching）

### 开启批处理

在 `config.yaml` 中设置：

```yaml
max_batch_size: 8
batch_timeout: 0.01
```

### predict 中的批处理路径

```python
def predict(self, x, **kwargs):
    if isinstance(x, list):
        # 批处理路径：x = [input1, input2, ...]
        return [self.model(item) for item in x]
    # 单条路径
    return self.model(x)
```

### 调优建议

| 场景 | max_batch_size | batch_timeout |
|------|---------------|---------------|
| 高并发、延迟敏感 | 4-8 | 0.001-0.01s |
| 吞吐优先 | 16-32 | 0.05-0.1s |
| GPU 显存受限 | 2-4 | 0.01s |

## 流式响应（Streaming）

### 开启流式

```yaml
stream: true
```

### predict 返回生成器

```python
def predict(self, x, **kwargs):
    for token in self.model.generate(x):
        yield token
```

`encode_response` 会逐块接收 `yield` 的值并流式返回给客户端。

## 自定义 Prometheus 指标

```python
from prometheus_client import Counter, Histogram

class MyAPI(LitAPI):
    request_counter = Counter("my_requests_total", "Total requests")
    latency = Histogram("my_latency_seconds", "Latency", buckets=[0.001, 0.01, 0.1, 1.0])

    def predict(self, x, **kwargs):
        self.request_counter.inc()
        with self.latency.time():
            return self.model(x)
```

指标自动通过 multiproc 模式聚合，可在 `:metrics_port/metrics` 查看。

## 版本控制

### 多版本并存

```
model_repo/
  my_model/
    1/
      model.py
      config.yaml
    2/
      model.py
      config.yaml
```

### 切换版本

```bash
# 加载指定版本
curl -X POST http://127.0.0.1:8000/v2/repository/models/my_model/load \
  -H "Content-Type: application/json" \
  -d '{"version": "2"}'

# 查看活跃版本
curl http://127.0.0.1:8000/v2/models/my_model
```

### 热重载

在 `config.yaml` 中启用：

```yaml
hot_reload: true
hot_reload_interval: 1.0
hot_reload_patterns:
  - "*.py"
  - "*.yaml"
```

修改 `model.py` 或 `config.yaml` 后自动重新加载，无需重启服务。

#### 自定义重载 Hook

你可以在 LitAPI 子类中可选实现 `on_file_changed(changed_files)`，自定义处理重载事件：

```python
def on_file_changed(self, changed_files):
    """热重载检测到文件变更时调用。"""
    for path in changed_files:
        print(f"文件变更: {path}")
    # 返回 True 继续标准重载流程，返回 False 跳过
    return True
```

## 模型生命周期 Hooks

LitAPI 子类可以**可选**实现三个 hook，在推理前后和就绪检查时执行自定义逻辑。

### on_request — 请求入队前

```python
def on_request(self, payload, request_meta):
    """在主进程收到请求、入队前调用。"""
    headers = request_meta.get("headers", {})
    auth = headers.get("authorization", "anonymous")
    payload["_auth"] = auth
    return payload
```

**`request_meta` 包含：**

| 字段 | 说明 |
|------|------|
| `headers` | 请求头字典 |
| `query_params` | URL 查询参数 |
| `client_host` | 客户端 IP |
| `method` | HTTP 方法（GET/POST/...） |
| `url` | 完整请求 URL |
| `path_params` | `{"model_name": ..., "version": ...}` |

### on_response — 响应返回前

```python
def on_response(self, response, response_meta):
    """在主进程收到 worker 响应、返回客户端前调用。"""
    response["_meta"] = {
        "model_name": response_meta.get("model_name"),
        "version": response_meta.get("version"),
        "status": response_meta.get("status"),
    }
    return response
```

**`response_meta` 包含：**

| 字段 | 说明 |
|------|------|
| `model_name` | 模型名 |
| `version` | 版本号 |
| `request_meta` | 上游 `on_request` 注入的原始元数据 |
| `status` | `"ok"` 或 `"error"` |

### health_check — 模型级健康检查

```python
def health_check(self):
    """GET /v2/models/{name}/ready 时调用。"""
    return {"status": "healthy", "gpu": 0.5}
```

返回的 dict 会附加到 `/ready` 响应的 `model_status` 字段。如果抛出异常，会被优雅捕获并返回 `{"status": "error", "error": "..."}`。

> 所有 hooks 均为可选。未实现时行为与标准 LitAPI 完全一致。

完整示例见 [`examples/11_hooks_and_endpoints`](../../examples/11_hooks_and_endpoints/)。

## 动态端点（自定义路由）

在 `model_repo` 根目录放置 `*_endpoint.py` 文件，可自动注册为 FastAPI 路由。

### 命名规则

文件名去掉 `_endpoint.py` 后缀即为路由路径：

| 文件名 | 路由 |
|--------|------|
| `health_endpoint.py` | `GET /health`（覆盖默认） |
| `status_endpoint.py` | `GET /status` |
| `webhook_endpoint.py` | `GET /webhook` |

### 基本写法

```python
# model_repo/health_endpoint.py
def handler(request, server):
    return {"status": "ok", "custom": True}
```

### 自定义 HTTP 方法

```python
# model_repo/webhook_endpoint.py
methods = ["POST"]

def handler(request, server):
    return {"received": True}
```

### 异步 Handler

```python
# model_repo/status_endpoint.py
async def handler(request, server):
    loaded = server.registry.list_loaded()
    return {"models": loaded}
```

### Handler 参数

- `request` — FastAPI `Request` 对象，可调用 `await request.json()`、`request.headers` 等
- `server` — `LightServer` 实例，可访问 `registry`、`model_manager`、`config` 等

完整示例见 [`examples/11_hooks_and_endpoints`](../../examples/11_hooks_and_endpoints/)。

## 辅助模块

`model.py` 同级目录下的 `.py` 文件可被导入：

```python
# model_repo/my_model/1/utils.py
def preprocess(x):
    return x.lower()

# model_repo/my_model/1/model.py
import utils

def decode_request(self, request, **kwargs):
    return utils.preprocess(request["text"])
```
